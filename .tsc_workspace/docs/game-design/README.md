# Game Design Workspace

Use this folder for player-facing design documents and game design references.

## Recommended Structure
- `gdd/`: main game design documents
- `systems/`: rules, economies, progression, combat, cards, encounters
- `content/`: cards, enemies, items, levels, events, rewards
- `ux/`: player flow, menus, HUD, readability, onboarding
- `art-direction/`: visual pillars, references, mood, animation notes
- `narrative/`: world, characters, lore, dialogue, quest structure
- `research/`: references, competitive notes, playtest findings

Keep high-level intent in `gdd/` and move deep feature detail into the more specific folders as the project grows.
