# Development Workspace

Use this folder for engineering-facing project documentation.

## Recommended Structure
- `architecture/`: technical architecture and decisions
- `systems/`: implementation notes for runtime systems
- `pipelines/`: build, content, asset, localization, release workflows
- `qa/`: test plans, bug triage, acceptance criteria
- `releases/`: changelogs, milestone notes, release checklists

Keep product design decisions in `game-design/` and engineering execution detail in `development/`.
