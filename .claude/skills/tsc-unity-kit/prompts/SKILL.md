# Prompts Module

## Purpose
Contains detailed instruction templates for code generation and auditing.

## Files
- **AuditChecklist.md**: Checklist for `$check` command. Validates code against TSC Iron Rules.

## When to Load
- `$check`: Load `AuditChecklist.md` to verify code compliance.
- Future: Add generation prompts for complex features.

## Data Source
Self-contained. No external mapping required.
