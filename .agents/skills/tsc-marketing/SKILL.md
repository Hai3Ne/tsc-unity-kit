# TSC Marketing Skill

## When to use this skill
- **Devlog:** When user runs `$promote [Platform]`.
- **Status:** When asking "How do I describe this feature to players?".

## How to Promote ($promote)
1.  **Analyze Work:** Read `.tsc_workspace/plans/active.md` to see what was recently completed `[x]`.
2.  **Consult Config:** Read `.tsc_workspace/docs/marketing/SOCIAL_STRATEGY.md` for tone.
3.  **Generate:** Create a draft post/tweet.
    - *Twitter:* < 280 chars, hashtags.
    - *Devlog:* Paragraphs, exciting language.
4.  **Confirm:** Ask user to review before "posting" (simulated).
