# TSC Audit Skill

## When to use this skill
- **Validation:** When user runs `$check`.
- **Review:** When asked to review or critique existing code.

## How to Check Code ($check)
1.  **Read:** `AuditChecklist.md` (located in this folder).
2.  **Scan:** The target file(s).
3.  **Execute:** Compare code against the checklist.
4.  **Report:** List violations (e.g., "Line 10: Public field detected").
